# Backtest migrasi RHI — 6 November 2026

## Kesimpulan

**Belum memenuhi klaim seluruh fitur dan integrasi bekerja 100%.** Inventaris baseline frontend lengkap. Ditemukan 21 file sumber backend yang belum masuk repo migrasi; file tersebut sudah dipulihkan dari arsip sumber. Fungsi yang sedang berjalan sebelumnya tetap tersimpan di delapan bundle runtime VPS. Ditemukan dan diperbaiki juga CORS gateway UAT yang menghalangi login dan pembacaan REST dari browser lokal.

Tiga halaman percakapan masih placeholder sejak aplikasi asal. Integrasi eksternal, backup Drive, sinkronisasi terakhir, dan pemeriksaan visual dua halaman masih memiliki pekerjaan terbuka. Pengujian ini tidak mengaktifkan cutover; staf tetap memakai aplikasi lama.

## Lingkungan dan kelengkapan

- Baseline frontend produksi: `5f406e0dff49a1c09f3a7c19b26fdf57c947da30`.
- 61 definisi rute, 49 halaman kanonis; tidak ada rute baseline yang hilang.
- 297 file frontend identik; lima perbedaan ditinjau: banner preview/UAT, stylesheet banner, origin undangan pengguna, normalisasi URL Functions, serta endpoint ekspansi tautan peta. Tidak ada file frontend baseline yang hilang.
- Delapan fungsi backend tercatat dengan versi/JWT bundle; seluruh entrypoint dan import relatif tersedia setelah pemulihan 21 file. Semua sumber backend lulus pemeriksaan sintaks TypeScript.
- Sumber bersama memiliki beberapa varian arsip per fungsi. Pemulihan file **bukan bukti bahwa setiap bundle dapat direproduksi dari satu pohon sumber ini**. Runtime mempertahankan bundle per fungsi yang telah diverifikasi; audit ini tidak menggantinya.
- UAT memakai database, Auth/JWT, Storage, Realtime, dan jaringan terpisah. Kredensial provider UAT berupa nilai uji; pengiriman eksternal dan scheduler tidak diaktifkan.
- Rekonsiliasi snapshot sebelumnya mencakup hash seluruh tabel sumber berisi data dan seluruh objek Storage. Ini membuktikan salinan pada waktu snapshot, bukan transaksi baru yang terus masuk ke aplikasi lama.

## Reproduksi

Dari repo migrasi, dengan baseline dan kredensial privat yang sesuai:

```sh
node scripts/audit-migration-coverage.mjs
npm run smoke:core-contracts
npm run typecheck:phase4
node scripts/test-vps-boundaries.mjs
npm run build
npm run lint
npm run dev:uat
# Terminal kedua, setelah tunnel UAT siap:
node scripts/smoke-uat-cors.mjs
node scripts/smoke-vps-realtime.mjs --uat
```

`deploy/backtest-extended.py` dijalankan di VPS yang identitasnya cocok dan hanya database `rhi_uat_20261106`. Script membuat fixture sementara dan membersihkannya, dengan `--cleanup-only` untuk pemulihan run yang terputus. Tidak menjalankan script tersebut ke produksi lama.

Bukti rinci disimpan privat di `.migration-local/feature-coverage-inventory.json`, `.migration-local/browser-coverage-20261106.json`, `.migration-local/uat-verification/`, dan log build/typecheck/lint. File kredensial serta respons bisnis tidak dimasukkan ke Git. Akun browser uji, session, dan fixture suite tambahan telah dibersihkan.
