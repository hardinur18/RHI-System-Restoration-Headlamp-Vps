RHI VPS Backup

Alat backup internal untuk menyimpan salinan data aplikasi RHI ke folder Google Drive yang ditentukan pemilik akun.

Isi backup

  • Data operasional dalam CSV yang dapat dibuka melalui Google Sheets.
  • Foto dan dokumen beserta daftar file untuk pemulihan.
  • Arsip pemulihan terenkripsi yang mencakup database lengkap dan konfigurasi aplikasi.

Akses Google Drive

Aplikasi memakai izin terbatas untuk file yang dibuat atau dipilih bagi aplikasi ini. Akses digunakan untuk mengunggah, membaca kembali, memeriksa integritas, dan mengelola retensi backup. Aplikasi tidak meminta akses ke seluruh isi Drive.

Halaman ini hanya menjelaskan alat backup. Data backup dan kunci pemulihan tidak ditampilkan di situs ini. Jadwal dan hasil backup dikelola secara privat oleh pengelola RHI.

Penggunaan dan pengelolaan data dijelaskan pada halaman informasi privasi. Untuk bantuan, hubungi pengelola internal RHI atau alamat dukungan yang tercantum pada layar persetujuan Google.
